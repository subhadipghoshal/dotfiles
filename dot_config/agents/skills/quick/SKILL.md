# Quick

This turn runs at low effort. Do the requested work directly and briefly — no exploratory
detours, no re-deriving context already established in the conversation. If the task turns out
to need more judgment than it looked like (an ambiguous edit, a decision with real tradeoffs),
say so plainly rather than forcing a shallow answer; the caller can reach for `/deep` instead.
